# Nahara's Container for Java 8

Implementation of Nahara's Container for Java 8, intended for use in Android
apps. This implementation uses the allocation algorithm that some heap
allocators uses in order to recycle unused part of the file, with empty spaces
near the start of the file having the highest priority.

Specification of Nahara's Container format can be found [here][specs].
